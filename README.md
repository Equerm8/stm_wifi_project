# stm_wifi_project
A communication system between two STMs using Wi-Fi to transmit data from sensors

What has been achieved:
1. A simple program was created to display data collected from sensors
2. Sensor readings were implemented on the NUCLEO-G071RB
3. A buzzer was implemented based on humidity levels. It beeps when humidity exceeds 60%
4. The WiFi module was implemented, and data transfer between modules was established.
5. The project was successfully completed

Issue detected: At random intervals, the temperature and humidity readings show zero. The cause of this issue has not been determined. The problem disappears after resetting the microcontroller
